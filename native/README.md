# The Good Pantry — Capacitor native wrapper

Mirrors the owner's euchre-game layout (`native/` next to the web app, not
inside it).

| Item | Value |
|---|---|
| appId | `com.josh17400.WellStocked` |
| appName | The Good Pantry |
| webDir | `../apps/web/dist` |
| Capacitor | 8.x |
| SQLite plugin | `@capacitor-community/sqlite` 8.x |

## Scripts

```powershell
# From repo root — build web, then sync both platforms
npm run cap:sync

# Or from this directory after a web build:
npm run sync
npm run sync:ios
npm run sync:android
```

## Platforms

`ios/` and `android/` are generated by `npx cap add` and committed so CI does
not need to re-scaffold. Fastlane lives at `ios/fastlane/` (TestFlight).

Do not run `cap open` on this Windows machine — there is no Xcode.
