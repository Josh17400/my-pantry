Migrations, RLS policies, and Edge Functions land here in later milestones.

**M0 handoff:** create a Supabase project in the owner's account and set:

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_ANON_KEY`

in `apps/mobile/.env` (gitignored). The client dependency and config module are already wired; no project or credentials are created in M0.
