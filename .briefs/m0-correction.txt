## What changed

You were fighting `expo-sqlite` on web ("Web fails on Drizzle's sync select path"). That
fight is over, because **web SQLite has been cut from the product entirely.**

Reason: `expo-sqlite` web is officially alpha and requires `Cross-Origin-Embedder-Policy` +
`Cross-Origin-Opener-Policy` headers for `SharedArrayBuffer`. Those headers are **origin-wide**
and break cross-origin popups and embeds — which means Google sign-in, AdSense, and Stripe.js
all become problems later. Even if you had won that fight, we would not have shipped it.

**`SPEC.md` has been rewritten (v2). Re-read it before you continue — the data model changed
substantially too.** Do not work from your memory of v1.

## The new platform shape

| Target | Data layer |
|---|---|
| iOS / Android | `expo-sqlite` + Drizzle, offline-first. **This is the real app.** |
| Web | **Supabase-direct + service-worker cache. NO local database.** Online companion. |

Same codebase, same routes, same components. Web simply requires a connection.
